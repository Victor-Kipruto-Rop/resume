Tech Stack & Tools

Detailed Engineering Toolkit

Production-tested tools and frameworks utilized across data pipelines, cloud infrastructure, and data quality testing.

Programming Languages

  • Python: Core language for scripting, pipeline orchestration (Pandas, NumPy, SQLAlchemy), and automated testing.
  • SQL: Advanced querying, recursive CTEs, and schema design on PostgreSQL and MySQL.
  • Shell / Bash: System administration, Docker scripts, and environment automation.

ETL & Pipelines

  • Apache Airflow: Orchestrating complex DAG designs and multi-stage ETL dependencies.
  • Apache Kafka: Building producer/consumer models for live transaction ingestion with real-time aggregation.

Cloud & DevOps

  • AWS: Implementing S3 for data lake storage and EC2 for hosting infrastructure.
  • Docker & Compose: Containerising full stacks (Airflow, Kafka, Postgres) for single-command reproducibility.

Warehousing & Architecture

  • Dimensional Modelling: Designing robust Star Schemas with Fact & Dimension tables.
  • SCD Type 2: Implementing Slowly Changing Dimensions to preserve full historical change timelines on customer metrics.

Data Quality & Reliability

  • Pytest: Comprehensive unit & integration testing (null injection, coercion failures).

Visualisation

  • Plotly: Producing live visualization outputs directly from Kafka consumer layers.
  • Jupyter Notebooks: Interactive data exploration and real-time streaming feedback.
